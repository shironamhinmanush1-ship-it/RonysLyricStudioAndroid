# 🎬 Lyric Studio Pro — Android APK বিল্ড নির্দেশিকা

তানভীর ভাই, আপনার সুবিধার্থে সবগুলি সেরা ফিচার (Rony Lyric Studio, Mobile Master এবং Lyric Studio V4) একত্রিত করে এই প্রজেক্টটি তৈরি করা হয়েছে। 

### 🌟 অ্যাপের মূল সুবিধাসমূহ:
1. **মোবাইল মাস্টার লেআউট:** স্ক্রিন স্ক্রল করলেও লাইভ প্রিভিউ উপরে ফিক্সড থাকে এবং বড় বড় টাচ বাটনে নিখুঁত সিঙ্ক করা যায়।
2. **বাংলা ফন্ট ও টাইপোগ্রাফি:** Hind Siliguri, Noto Serif Bengali, Baloo Da 2 ইত্যাদি ফন্ট সাপোর্ট।
3. **মাল্টি-রেশিও:** 9:16 (Shorts/Reels), 16:9 (YouTube), এবং 1:1 (Square)।
4. **ভিজ্যুয়াল ইফেক্টস:** রেইন (বৃষ্টি), বোকেহ গ্লো, স্পার্কল এবং ডার্ক ওভারলে অ্যাডজাস্টমেন্ট।
5. **এক্সপোর্ট:** সরাসরি MP4 / WebM ভিডিও রেন্ডার ও ডাউনলোড (720p এবং 1080p)।
6. **অডিও + ব্যাকগ্রাউন্ড ভিডিও/ইমেজ:** যেকোনো গান ও ব্যাকগ্রাউন্ড ভিডিও লুপ সাপোর্ট।

---

### 🚀 GitHub Actions দিয়ে ১ ক্লিকে APK বানানোর নিয়ম:

১. এই ZIP ফাইলটি আপনার ফোনে বা পিসিতে আনজিপ (Extract) করুন।
২. আপনার GitHub অ্যাকাউন্টে যান এবং একটি নতুন **New Repository** তৈরি করুন (যেমন: `lyric-studio-pro`)।
৩. আনজিপ করা ফোল্ডারের **ভেতরের সব ফাইল ও ফোল্ডার** গিটহাবের রুট ডিরেক্টরিতে আপলোড (Upload files) করুন।
   *(খেয়াল রাখবেন `.github/workflows/build-apk.yml`, `app/`, `build.gradle` ইত্যাদি যেন সরাসরি রিপোজিটরির শুরুতে থাকে)*
৪. কমিট (Commit changes) করার পর গিটহাবের **Actions** ট্যাবে যান।
৫. সেখানে **"Build Lyric Studio Master APK"** দেখতে পাবেন। ডানপাশে **"Run workflow"** বাটনে চাপ দিন।
৬. ৩-৪ মিনিটের মধ্যে বিল্ড সফল (সবুজ টিক ✅) হবে।
৭. বিল্ডের ভেতরে ঢুকে **Artifacts** সেকশন থেকে `LyricStudio-Master-debug-APK` ডাউনলোড করে নিন।
৮. জিপটি খুলে `app-debug.apk` আপনার ফোনে ইন্সটল করলেই ফুল অ্যাপ চালু হয়ে যাবে!
